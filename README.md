# AI 3D Particle Hand Gesture Web App ✨🤖

Aplikasi Web 3D Interaktif berbasis **Three.js** dan **MediaPipe Hands AI**, terinspirasi dari video viral TikTok di mana gerakan tangan di depan webcam mengubah puluhan ribu partikel neon menyala menjadi berbagai bentuk 3D yang memukau!

---

## 🚀 Cara Menjalankan

### Cara 1 (Paling Mudah di Windows):
Cukup **klik dua kali (double click)** file:
`start.bat`

Browser akan otomatis terbuka di `http://localhost:5173`.

### Cara 2 (Terminal / Command Prompt):
```bash
npm run dev -- --open
```

---

## 🖐️ Panduan Gestur Tangan (Sesuai Video TikTok)

Arahkan tangan ke depan webcam Anda (pastikan pencahayaan cukup):

| Gestur | Jari | Bentuk Partikel | Efek Khusus |
|---|---|---|---|
| ✌️ **Peace** | 2 Jari | **Teks "I LOVE YOU"** | Teks neon bercahaya (dapat diubah dengan teks kustom Anda sendiri!). |
| ✊ **Fist / Kepalan** | 0 Jari | **3D Heart (Hati)** ❤️ | Berdenyut seperti detak jantung (*heartbeat pulse*) dengan efek suara bass. |
| ☝️ **Pointing** | 1 Jari | **Planet Saturnus** 🪐 | Bola inti emas bercahaya dikelilingi cincin orbital miring yang berputar. |
| 🖐️ **Open Palm** | 5 Jari | **Galaksi Kosmik** 🌌 | Spiral nebula 4 lengan dengan pusat bintang putih cemerlang. |
| 🤟 **Tiga Jari** | 3 Jari | **Bunga / Kembang Api** 🎆 | Kelopak teratai mekar dan letupan kembang api emerald. |
| 🖖 **Empat Jari** | 4 Jari | **DNA Double Helix** 🧬 | Untaian ganda heliks berputar dengan gradien ungu & cyan. |
| 👌 **Pinch (Cubit)** | Jempol + Telunjuk | **Singularity Gravitasi** ✨ | Partikel tersedot ke ujung jari, meledak saat cubitan dilepas! |

## 🎨 Fitur Tambahan Keren
- **Interaksi 3D Ruang Nyata**: Gerakkan tangan Anda ke kiri/kanan/atas/bawah di webcam untuk memiringkan dan memutar partikel secara langsung.
- **Teks Kustom**: Ketik nama pasangan, ucapan, atau pesan apa saja di kolom *"TEKS 2 JARI"* lalu lakukan gestur ✌️.
- **Cyberpunk HUD & Skeleton AI**: Tampilan webcam di pojok kiri atas memperlihatkan sendi tulang tangan bercahaya neon secara real-time.
- **Web Audio Synth**: Dilengkapi efek suara futuristik yang otomatis berbunyi harmonis setiap partikel bertransformasi.
- **Tema Warna**: Pilihan palet Cyan Cyberpunk, Ruby Love, Golden Saturn, Matrix Emerald, dan Rainbow.
- **Pengatur Kerapatan Partikel**: Ubah jumlah partikel dari 6.000 hingga 25.000 partikel serta ukuran partikel sesuka hati.
- **Screenshot HD**: Ambil foto estetik partikel kapan saja dengan tombol 📸 *Screenshot*.
